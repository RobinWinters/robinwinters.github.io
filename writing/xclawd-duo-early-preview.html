EARLY DEVELOPMENT PREVIEW · OCTOBER 8, 2026

Xclawd Duo: an early iPhone Duo IDE preview

I’m building Xclawd Duo, an AI-enabled IDE for iPhone Duo. This early preview explores a coding workspace that changes with the device: choose a project while folded, open it for chat and code, and use the keyboard in tabletop mode.

And yes, those are Mac OS X Aqua and Windows NT-inspired themes. A small coding workspace can still have some personality.

Full 57-second MP4 · Original LinkedIn post

What the recording shows

  • A folded project picker with an “Open your Duo to continue” prompt.
  • Chat, Code and Changes views, with chat and the editor side by side in the wider layout.
  • An on-screen keyboard and coding punctuation controls in the tabletop-oriented editing view.
  • Appearance changes between Aqua, dark and Windows NT-inspired themes.

This is an early, rough development build. The focus of this clip is the interface and device layouts; it is not a release announcement. The recording is silent.
